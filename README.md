# SSS - Production-Grade MERN E-Commerce Application

A full-stack, interview-ready e-commerce web application built using the MERN stack (MongoDB, Express, React, Node.js) with Razorpay payment integration, JWT authentication, and an Admin dashboard.

## Tech Stack
- **Frontend**: React 18 (Vite), React Router v6, Tailwind CSS, Lucide Icons, Axios
- **Backend**: Node.js, Express.js (MVC Pattern), Helmet, CORS, Rate Limiting
- **Database**: MongoDB Atlas / Mongoose
- **Authentication**: JWT & bcryptjs
- **Payment Gateway**: Razorpay (Test Mode)

## Project Structure
- `/server` - Express REST API backend
- `/client` - Vite + React modern frontend
